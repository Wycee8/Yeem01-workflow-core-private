## Project Authority Pack / PAP

`-pap` means this project's authority bundle: this charter plus any active UI/UX
authority, decisions, build or implementation packet, reference index, and
validation/read-order docs. PAP is a bundle label, not a separate authority.

`-pap design` is the canonical design-authority facet; `-dap` is its thin
read-only alias. It resolves existing design sources and does not require a
`DAP.md`, `DESIGN_AUTHORITY.md`, or other duplicate authority file.

## Split-out candidates

Create companion docs only when this charter becomes hard to scan or a section
needs independent ownership/review:

- `BUILD_PACKET.md` for a detailed build slice
- `IMPLEMENTATION_PLAN.md` for detailed execution sequencing
- `DECISIONS.md` for decision history
- `PRODUCT_UIUX_DESIGN_AUTHORITY.md` for product UI/UX design law and promoted design decisions
- `UX_GUIDELINES.md` for lightweight reusable product/design guidance when a full authority doc is not justified
- `AUDIT_BRIEF.md` for external review
