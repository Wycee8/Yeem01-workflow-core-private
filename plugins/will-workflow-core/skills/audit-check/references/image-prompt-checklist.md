# Image Prompt Checklist

Use this pre-generation quality gate for AI image prompts.

## Core elements

- [ ] **Subject** — Who or what is clearly defined
- [ ] **Context** — Setting, time, or action is described
- [ ] **Visual style** — Intended rendering style is explicit
- [ ] **Technical parameters** — Lighting, camera, or resolution guidance is present

## Subject clarity

- [ ] **Specificity** — The subject is not generic
- [ ] **Pose or expression** — Included when relevant
- [ ] **Colour** — Primary palette is identified
- [ ] **Composition** — Framing or viewpoint is named

## Platform fit

- [ ] **Renderer syntax** — Parameters match the chosen renderer
- [ ] **Text treatment** — Rendered text is limited and explicit when needed
- [ ] **Prompt form** — Instructions avoid ambiguous possibility language

## Brand and originality

- [ ] **Brand palette** — Relevant brand colours are referenced
- [ ] **Brand elements** — Mark or graphic-system guidance is included when needed
- [ ] **Tone** — The intended aesthetic is consistent
- [ ] **Original concept** — The prompt does not ask for direct copying
- [ ] **Reference disclosed** — Inspiration is identified when applicable
