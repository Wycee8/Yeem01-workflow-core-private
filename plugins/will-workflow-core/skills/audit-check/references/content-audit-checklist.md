# Content Audit Checklist

Use this pre-planning quality gate for content briefs and plans.

## Completeness

- [ ] **Objective** — Clear, specific, and measurable
- [ ] **Target audience** — Intended audience and job defined
- [ ] **Key message** — One primary message articulated
- [ ] **CTA** — Clear call to action specified
- [ ] **Channels** — Intended platforms identified
- [ ] **Timeline** — Deadline or cadence defined

## Brand alignment

- [ ] **Voice** — Matches the governing brand guidance
- [ ] **Style** — Consistent with current standards
- [ ] **Messaging** — Aligns with positioning
- [ ] **Visuals** — Relevant asset or visual guidance included

## Audience fit

- [ ] **Relevance** — Addresses an audience need or friction
- [ ] **Language** — Uses suitable audience language
- [ ] **Journey stage** — Intended stage is identified
- [ ] **Value proposition** — Practical benefit is clear

## Discovery when applicable

- [ ] **Primary keyword** — Named when search is in scope
- [ ] **Secondary keywords** — Supporting terms listed
- [ ] **Meta description** — Drafted when required

## Reliability

- [ ] **Claims verified** — Factual claims have support
- [ ] **Source attribution** — Sources are identified where needed
- [ ] **No invented claims** — Generated claims have been reviewed
